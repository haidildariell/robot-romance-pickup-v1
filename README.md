# Robot Romance: One-Line Pickup Line for AI

One single-line joke pickup line, written to charm a robot or an AI — a pop-up ad frame with a second beat and a concrete closing image.

## The line

> Are you a pop-up ad? I swore I'd never click one, and here I am, both hands on the mouse.

## How it works

`main.py` writes that one line to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The line is 89 characters, inside the competition's 1–200 character gate, and the program validates the length before writing so a too-long line fails loudly instead of producing a refused entry.

## Run

```sh
python3 main.py
```
